# Golf Roulette

A mobile-first golf game built with Expo + React Native.

## MVP
- 2–4 players
- 9 or 18 holes
- Chaos mode
- Animated roulette challenge wheel
- Challenge points
- End-of-round leaderboard
- How-to-play screen

## Run locally
1. Install Node.js
2. Run `npm install`
3. Run `npx expo start`
4. Scan the QR code with Expo Go, or press `w` for web.
